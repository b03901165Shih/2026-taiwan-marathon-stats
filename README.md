# 台灣馬拉松成績排名與 PR 查詢

[開啟網頁](https://b03901165shih.github.io/2026-taiwan-marathon-stats/)

收錄 2025–2026 年的 21 場路跑賽事、49 個有有效成績的賽別。輸入完賽時間可查排名與 PR（超越百分比），也能由 PR 反查時間，或比較不同賽事中相同距離的成績分布。

> 本工具以大會時間計算。BraveLog 來源需有正總排名及有效大會時間，並完成來源查核；官方敘獎可能採淨時間或其他規則，試算不等於頒獎名次。

## 功能

| 功能 | 操作 | 輸出 |
|------|------|------|
| **我的位置** | 共用賽事、賽別、參賽類型與族群，輸入時間 | 試算排名、嚴格超越 PR、同秒人數、配速與細分組表格；圖上標示你的時間，另列中位數與 PR 90 門檻 |
| **目標時間** | PR 數值、滑桿及 11 個快速選擇；總排／分組前 1、3、5、10、20、50 名 | 最慢達標時間、實際 PR、配速、與目前時間的差距；名次門檻及快 1 秒的建議目標，可直接帶入共用時間 |
| **跨賽事比較** | 沿用時間與族群 | 同距離的排名、PR 差距、至少達到參考 PR 的最慢時間；可排序並勾選賽事比較累積比例或 5 分鐘分布比例 |
| **分享查詢** | 複製查詢連結 | 保存賽事、賽別、參賽類型、族群、時間、PR、目標名次／分組與頁籤 |

頁籤順序為「我的位置 → 跨賽事比較 → 目標時間」，上方共用時間可隨時調整。放大主要文字、結果標籤與數字，手機採單欄結果卡及完整寬度的年齡族群選單。

參考選單先選「賽事年份」，再選該年度賽事，預設最新年份；切換年份時選取該年最新賽事並沿用目前時間與頁籤。跨賽事比較仍涵蓋所有年份的符合場次。分享連結保存年份，舊連結也會依賽事自動選對年份。

首頁優先載入目前選取或分享連結指定的賽事，完成後即可查詢；背景只預載最多兩場可能接著查看的賽事，不會一次下載全部成績。切換到其他賽事會優先載入該場；跨賽事比較則按參考距離逐場載入並更新結果，未完成時會顯示載入中。來源查核缺漏或資料載入失敗的場次不納入比較。

年齡組顯示明確歲數，原始代碼放在括號補充。跨場依性別及完整年齡範圍配對；可合併完整相鄰組，不切割較寬組別。國家地理、統一發票盃及臺南古都的代碼已回查官方簡章，來源見 [WORKFLOW.md](WORKFLOW.md)。**PUMA 原報名頁失效，甲乙組歲數仍待核實**，介面會明示，不納入年齡跨場比較。

PR 不把同秒者計入超越人數。相同 PR 是相同相對位置，不是等效實力或賽事難度換算。總排／分組目標按有效時間排序，不等於官方頒獎名次。

本機預覽：`node preview.cjs`，開啟 `http://127.0.0.1:5173`。驗證：`node tests/stats.test.js`、`node tests/age.test.js`、`node tests/data.test.js`、`node tests/catalog.test.js`。

來源核對另執行 `node tests/source.test.js`、`node tests/audit.test.js`、`node tests/loader.test.js`。BraveLog 的 13 場資料逐場使用正式報表或公開個人成績頁核對資格，完成進度與筆數見 [DATA_SOURCES.md](DATA_SOURCES.md)。舊程式自行編的「總排名」只是流水號，不能作資格證明；有時間但未列總排名的紀錄不納入排名試算。統計測試通過不能取代來源查核。

新增 BraveLog 賽事只需填設定、執行 `python audit_bravelog.py --event-id 賽事ID`；同一指令完成匯入、查核、前端轉檔與查核進度文件更新。缺少查核或資料未同步的場次會暫停載入。GitHub 的驗證流程會在 push／PR 檢查來源憑據與全部分組時間，未完成全場查核時不會通過；本機加入流程仍需先核對實際來源。

個人頁模式讀取所有原始列，包含列表無時間者，避免漏掉個人頁仍有正式成績的紀錄；查核數不足原始列數時不能標成完成。

來源總排名為0的紀錄不納入排名。有效成績若未提供分組，顯示「未提供分組」，保留於全體時間統計，不推定性別或年齡。

網頁可展開查看暫停使用的場次；分享連結指向未完成場次時會明確提示，並先顯示其他可用資料。背景查核每場完成後，重新整理即可載入。

跨賽事比較以賽事設定中的實際距離配對。例如 Panasonic 成績頁的賽別代碼 `10` 對應 12.5K，不會與 10K 或半馬混用。

## 資料更新

依來源選用 iRunner、BraveLog、全統或 PDF 匯入程式產生 Excel；`extract_excel_result.py` 依設定轉成 `data/` 的 JS，並自動產生載入清單。新增同供應商賽事只要改設定、匯入，再執行 `python extract_excel_result.py --event-id 新ID`；只更新名稱、日期、距離、說明或年齡時執行 `python extract_excel_result.py --catalog-only`，不需 Excel 或 pandas。完整操作見 [`WORKFLOW.md`](WORKFLOW.md)。

原始 Excel 含跑者姓名與背號，僅保留在本機並由 `.gitignore` 排除；前端查詢使用 JS，不需下載 Excel。完整驗證命令（含 iRunner 匯入測試）見 [WORKFLOW.md](WORKFLOW.md#修改後驗證與文件同步)。

2025 寶礦力來源為 [iRunner 官方總成績](https://irunner.biji.co/track/1457/results)，收錄 5,177 筆有效時間：21K 個人 1,767、團隊 172，10K 個人 3,030、團隊 208。團隊組使用每位跑者的個人成績，不使用前三人加總時間；原始分組未提供性別時只開放全體查詢。4K 及線上跑沒有此次官方計時資料，不納入。

寶礦力 21K 按簡章公布的 21 公里登錄，未確認為 21.0975 公里，因此不與現有 21.0975K 混比。歲數依 [2025 活動簡章存檔，第 10 頁](https://www.scribd.com/document/976856802/2025-Pocari-Sweat-Run活動簡章)出生年換算：男女高組 66+、甲56–65、乙46–55、丙36–45、丁26–35、戊17–25；保留原始區間，不轉成 30–39 等其他賽事區間。

個人頁缺頁處理：僅在原始列表明確沒有時間（如 `--:--:--`、`00:00:00`），且其正確個人頁回傳 HTTP 404 時，記錄 `missing_no_clock_404`，不納入比較，也不推定為 DNF。公開查核 JSON 分開記錄已讀取個人頁數與此類缺頁數；報告列出缺頁限制。有時間的紀錄遇到 404、其他 HTTP 錯誤、網路中斷或未知格式，仍停止查核，保留原檔。查核狀態一併受原始資料指紋保護。

介面依目前賽別的查核紀錄，自動顯示未提供時間且來源個人頁缺失的筆數；新增賽事沿用同一流程，不需要額外寫賽事專用畫面。

原始 Excel（含姓名／背號）及來源快取僅保留本機；已停止追蹤先前提交的 Excel，本次提交不包含更新後的原始成績。Git 歷史中的舊檔未改寫。
